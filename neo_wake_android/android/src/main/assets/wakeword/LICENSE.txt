This directory ships the chorus6 wake-word bundle. Both files are in-house,
proprietary. All rights reserved.

- chorus6_frontend.onnx  raw 16 kHz audio [batch,32000] -> log-Mel [batch,200,40]
                         (AGC v2 + 40-bin log-Mel + per-window mean subtraction)
- chorus6.onnx           log-Mel [batch,200,40] -> softmax probs [batch,3]
                         (background, wake_up_neo, neo_wake_up)

sha256 values are recorded in the bundle's chorus6.config.json.
